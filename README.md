# Coolors.co — Atividade HTML e CSS

## Sobre o projeto

Projeto acadêmico de desenvolvimento web com temática baseada no Coolors.co, plataforma voltada à criação e combinação de paletas de cores.

O objetivo é aplicar conhecimentos de HTML e CSS na construção e organização de páginas web.

## Tecnologias utilizadas

- **HTML5:** estruturação do conteúdo.
- **CSS3:** estilização e organização visual das páginas.

## Como visualizar

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Acesse a pasta `html`.
4. Abra o arquivo `menu1.html` no navegador ou utilize o Live Server.
